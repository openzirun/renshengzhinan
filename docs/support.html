技术支持 · Support

遇到问题、发现内容错误或希望提出建议，请通过 GitHub Issues 联系项目维护者。请说明设备型号、iOS 版本、应用语言、问题发生步骤及预期结果。提交 Issue 需要 GitHub 账号。

Issue 是公开的，请不要提交审核联系资料、密码、医疗记录或其他敏感信息。

常见问题

是否需要联网或注册？

正文已内置，无需账号即可离线阅读。打开外部引用与支持网站需要联网。

如何切换语言？

点击首页右上角地球按钮，或进入“关于”的语言入口。各语言版本的内容数量和地区适用性不同；补充专题和内置 PDF 仅提供中文。

收藏与行动保存在哪里？

保存在本机，按语言分别记录。切换回原语言即可查看该语言的记录。本应用没有自己的跨设备同步服务。

如何添加今日一读小组件？

安装并打开应用后，长按主屏幕空白区域，选择添加小组件，搜索“高性价比人生指南”。语言与内容刷新由系统调度，可能有短暂延迟。

下载、付款或退款问题

应用无订阅或内购，下载后包含全部内置内容。App Store 的付款及退款由 Apple 处理，请访问 Apple 问题报告。

内容能作为专业建议吗？

内容用于一般知识阅读，不能替代针对个人情况的医疗、法律或财务建议。紧急情况请联系当地急救服务。

Support — English

Report bugs, content corrections or suggestions through GitHub Issues (a GitHub account is required to post). Include your device, iOS version, selected language, reproduction steps and expected behavior. Issues are public; never post sensitive information.

  • Bundled reading content works offline without an account. External links require internet access.
  • Change language using the globe button on Home or the language option in About. Content varies by edition; supplementary essays and the bundled PDF are Chinese only.
  • Bookmarks and actions are stored locally, separately for each language. There is no developer-operated cross-device sync.
  • To add the daily widget, open the app once, then use the Home Screen widget gallery. iOS controls refresh timing.
  • All built-in content is included with the app. There are no subscriptions or in-app purchases. For App Store billing or refund requests, contact Apple.
